# 🚀 RoboVAI Social Media Autopilot (منظومة النشر والتسويق الذاتي)

منظومة متكاملة ومجانية 100% لإدارة ونشر المحتوى التسويقي لكاشير **RoboVAI PRO POS v6.0** على منصات التواصل الاجتماعي (فيسبوك، تويتر، إنستجرام، وتليجرام) باستخدام الذكاء الاصطناعي (**Grok / Google Gemini**).

---

## 🌟 المميزات الرئيسية:
1. **لوحة تحكم بصرية تفاعلية (Streamlit Dashboard)**:
   - اختيار أفكار البوستات من جدول حملات جاهز.
   - اختيار صور شاشات النظام المدمجة (18 موديول) أو رفع صور جديدة.
   - توليد 4 صيغ مخصصة بنقرة واحدة (Facebook Storytelling، X Hook، Instagram Caption، Telegram Broadcast).
   - النشر بضغطة زر واحدة على جميع المنصات دفعة واحدة.
2. **غرفة تحكم ذكية من الموبايل عبر تليجرام (Admin Bot)**:
   - ارسل أي صورة أو فكرة من موبايلك للبوت.
   - يقوم البوت فوراً بصياغة المحتوى ويعطيك زراً للموافقة: `[🚀 انشر الآن في كل المنصات]`.
3. **مجانية 100% وبدون أي تكاليف سيرفرات**:
   - تدعم **Google Gemini 2.0 Flash المجاني تماماً** (1,500 طلب مجاني يومياً من Google AI Studio).
   - تدعم الاستضافة المجانية على **Streamlit Community Cloud**.

---

## 🛠️ كيفية التشغيل المحلي السريع:

1. افتح التيرمينال في هذا المجلد:
   ```bash
   cd F:\Raw\kasher\kasher\robovai-social-autopilot
   ```

2. قم بتثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```

3. اضبط مفاتيحك في ملف `.env` (انسخ من `.env.example`):
   ```bash
   copy .env.example .env
   ```

4. شغّل لوحة التحكم في المتصفح:
   ```bash
   streamlit run app.py
   ```

5. (اختياري) لتشغيل بوت التحكم على تليجرام:
   ```bash
   python bot.py
   ```

---

## ☁️ كيفية الرفع على Streamlit Community Cloud (مجاناً للأبد):
1. ارفع مجلد المشروع على حسابك في GitHub.
2. ادخل على [share.streamlit.io](https://share.streamlit.io/).
3. اضغط **New App** واختر المستودع وملف `app.py`.
4. في قسم **Secrets**، انسخ محتويات ملف `.env` لحفظ المفاتيح بأمان.
5. سيعطيك رابطاً عالمياً سريعاً للوحة التحكم يمكنك فتحه من أي مكان!
